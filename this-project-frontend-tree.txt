
ความหมายสัญลักษณ์
- 👉 = คลิก / กดปุ่ม
- 📍 = URL

- 📰 = แสดงรายละเอียด (จากการ fetch)
- 📝 = Form
- 📚 = List / รายการ (แบบหลายรายการ - จากการ fetch)

- 🔵 = ปุ่ม Redirect ไปต่อ
- 🟢 = ปุ่ม Create
- 🟡 = ปุ่ม Edit
- 🔴 = ปุ่ม Delete
- ⚪ = ปุ่ม เลือก (ใช้คู่กับรายการจากการ fetch)
